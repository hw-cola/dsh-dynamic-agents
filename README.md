# @dsh/dynamic-agents

DSH Web 动态上下文插件：在空白会话的新建行提供「动态AGENTS.md」下拉多选控件（会话开始后该行隐藏），按全局/工作区维护可勾选、可编辑、可拖拽排序的上下文规则，注入会话系统提示。

## 功能

### 功能一：新建会话行里的上下文多选控件

空白会话的 New Session 行（输入框上方、任务/模式控件之后）显示一个「动态AGENTS.md」下拉按钮，并显示当前已勾选数量徽标；会话开始后该行整体隐藏，控件随之消失：

- 面板分「全局」与「当前工作区」两组，各自支持勾选、全选/取消全选、新增、编辑、删除（二次确认）、查看完整内容；
- 新增/编辑规则需填写名称与内容，保存后该会话首次请求时即注入系统提示，无需重启；
- 每条规则行带拖拽手柄：拖动后规则行会悬浮并跟随指针、松手落位，也可聚焦手柄后按 `↑` / `↓` 移动；松手（或按键）即保存；
- 面板自适应定位：窗口缩放、滚动或内容变化时自动保持在视口内，手机端下同样可用；
- 视觉与交互对齐 DSH 官方风格：面板卡片与官方菜单同款设计令牌，按钮使用官方组件，输入框/文本域自绘并对齐官方视觉，面板 portal 到顶层并可叠于模态弹窗之上，支持 Escape 关闭。

### 功能二：两级规则库（全局共享 + 工作区独立）

- **全局规则库**：`~/.dsh/dynamic-agents.json`（`$DSH_HOME` 环境变量优先），所有工作区共享的规则定义，不含勾选状态；
- **工作区规则库**：`<工作区>/.dsh/dynamic-agents.json`，存放该工作区的规则与勾选状态；**不含任何每会话数据**；
- 全局规则的勾选也由工作区文件控制（全局规则 id 带 `g-` 前缀），因此不同工作区可以各自勾选不同的全局规则；
- 新增到全局库的规则会自动勾选到当前工作区；删除全局规则后，各工作区的残留勾选自动失效，不会残留无效引用；
- 规则顺序保存在各自的 `contexts` 数组里：全局组排序写入全局库（所有工作区共享），工作区组排序写入工作区文件。

### 功能三：勾选规则注入会话系统提示

- 勾选内容按「全局在前、工作区在后」的顺序合并，以 `## 规则名` + 规则内容的形式注入会话系统提示；
- 同组内按规则**列表顺序**（可拖拽调整）注入，而不是按勾选先后顺序；
- **会话开始即固定**：会话第一次组装系统提示词时，把当时生效的规则捕获到宿主进程内；之后该会话的提示词只使用这份捕获结果，其他会话修改规则库不会改变它；
- 捕获只存在于进程内存（`WeakMap`），**不写入任何配置文件，也不新增 sidecar 文件**，规则库文件大小与会话数量无关；
- 同工作区的新会话自动沿用上次勾选结果，并在首次请求时按最新规则库固定；
- 会话首个回合开始前会等待配置加载完成，避免首回合漏注入；
- **取舍**：重启 dsh 或热重载插件后，进行中会话会在下一次请求时按当前规则库重新固定一次；只要进程不重启，已开始会话的提示词始终不变；
- 升级到 v1.3.0 后，已有会话的提示词会去掉旧版标记并重新固定一次（一次性）。

### 功能四：会话开始后控件自动隐藏

- 会话开始后，New Session 行（含「动态AGENTS.md」控件）整体卸载，控件随之消失；
- 规则在首次组装系统提示词时已经固定；要修改规则，新建一个空白会话，在它的 New Session 行里编辑，新会话首次请求时再固定；
- Host 端会拒绝已开始会话的所有修改请求，作为安全兜底；
- 不持久化任何会话级状态；fork/resume 的会话按“首次组装捕获”规则处理。

### 功能五：配置文件热刷新（无需重启 dsh）

- 宿主进程会为全局/工作区配置文件记录版本令牌；新建会话、会话首回合前、打开面板或任意面板操作时都会先比对版本，变化才重新读盘；
- 因此手动或由其他实例修改 `~/.dsh/dynamic-agents.json`、`<工作区>/.dsh/dynamic-agents.json` 后，新会话即可生效，不必重启 dsh；
- 刷新时若文件读取/解析失败，会保留上一份可用状态，避免损坏内容或空状态覆盖现有配置。

## 安装

前置要求：本机已安装 [dsh](https://github.com/deepseek-ai/deepseek-harness) 与 [pnpm](https://pnpm.io/)（`dsh plugin` 通过 pnpm 安装插件）。

### GitHub 直装

```sh
dsh plugin --profile web add "git+https://github.com/hw-cola/dsh-dynamic-agents.git"
```

钉到指定版本（按 tag 锁定）：

```sh
dsh plugin --profile web add "git+https://github.com/hw-cola/dsh-dynamic-agents.git#v1.3.0"
```

### 本地开发

```sh
dsh plugin --profile web add "link:${PATH}/dsh-dynamic-agents"
```

> `${PATH}`为下载源码的路径

## 更新

```sh
dsh plugin --profile web update @dsh/dynamic-agents
```

若 pnpm 对 git 依赖的更新不生效，先卸载再重新安装：

```sh
dsh plugin --profile web remove @dsh/dynamic-agents
dsh plugin --profile web add "git+https://github.com/hw-cola/dsh-dynamic-agents.git"
```

## 卸载

```sh
dsh plugin --profile web remove @dsh/dynamic-agents
```

安装后请重启 `dsh web`（让插件的 cordis 补丁层生效）并刷新浏览器页面；卸载后刷新页面即可恢复原生布局。

> 卸载不会自动删除数据文件：全局规则库（`~/.dsh/dynamic-agents.json`）与工作区规则库（`<工作区>/.dsh/dynamic-agents.json`）需手动清理。

> 兼容性：插件在 DSH `0.1.7-rc.1` 上开发，并在 `0.2.1-rc.3` 上验证。客户端 API 仍在迭代，DSH 大版本升级后若功能异常，请检查本仓库是否有对应适配版本。

> 会话固定说明：规则捕获保存在宿主进程内存中，不落盘。重启 dsh 或热重载插件后，进行中的会话会在下一次请求时按当前规则库重新固定一次；之后保持不变。如果要求跨重启也完全冻结，需要额外持久化每会话状态，本插件有意不这样做。
